# 내가 감독이라면?
 
**MatchplanXI: 고도와 체력이 승부를 바꾸는 전술 시뮬레이터**
 
**🔗 Live: https://jhwn223.github.io/MatchplanXI/**
 
2026 월드컵 실제 데이터를 활용한 드래그 앤 드롭 전술보드입니다. 경기장 고도, 팀 휴식일, 최근 출전 시간, 국가대표 경험(caps)을 반영해 실시간으로 "고지대 컨디션 지수"를 계산하고, 실제 대진을 따라 조별리그부터 결승까지 플레이할 수 있습니다.
 
---
 
## 실행 방법
 
**요구 사항**: Node.js 20 이상 (개발 환경 v24.18.0), npm
 
```bash
git clone https://github.com/jhwn223/MatchplanXI.git
cd MatchplanXI
npm install
npm run dev            # 개발 서버 (http://localhost:5173)
```
 
| 명령 | 설명 |
|---|---|
| `npm run dev` | 개발 서버 실행 |
| `npm run build` | 타입 검사 후 프로덕션 빌드 (`tsc -b && vite build`) |
| `npm run preview` | 빌드 결과 로컬 확인 |
| `npm run lint` | oxlint 정적 분석 |
| `npm test` | 전체 테스트 (vitest, 23개 파일 / 122개 케이스) |
| `npm run test:match` | 경기 엔진 보정 테스트만 실행 |
| `npm run sync:player-photos` | Wikimedia Commons에서 선수 사진·출처 갱신 |
| `npm run sync:player-photos -- --team=KOR` | 특정 대표팀만 갱신 |
 
배포는 `npx gh-pages -d dist`로 GitHub Pages에 올립니다. 배포 경로는 `vite.config.ts`의 `base: '/MatchplanXI/'`를 따릅니다.

## 핵심 기능
 
```
국가 선택 → 팀 허브(일정·순위·진출 확률) → 라인업·전술 → 라이브 경기
        → 하프타임 조정 → 결과 분석 → 다음 경기 → 32강~결승 → 대회 개인상
```
 
### 대회 진행
 
- **48개국 중 선택** — 실제 2026 월드컵 조 편성과 일정을 그대로 사용합니다.
- **조별리그 3경기** — 내 경기는 직접 플레이하고, 다른 조 경기는 전력(Elo)과 실제 스쿼드 능력으로 시뮬레이션됩니다. 다른 팀도 나와 같은 매치데이 속도로 진행돼 순위표가 항상 같은 시점을 보여줍니다.
- **진출 확률** — 몬테카를로 시뮬레이션으로 32강 진출 확률을 매 시점 계산합니다. 2026 포맷(각 조 1·2위 24팀 + 3위 중 상위 8팀)이라 미완료 조 전체를 함께 돌립니다.
- **토너먼트** — 실제 Round of 32 슬롯 구조를 따라 32강 → 16강 → 8강 → 4강 → 3·4위전 → 결승. 내가 탈락해도 대회는 계속 진행돼 우승팀이 결정됩니다.
- **대회 개인상** — 전체 누적 기록으로 득점 / 어시스트 / 최소 실점 GK Top 3를 집계합니다.
### 스쿼드와 라인업
 
- **드래그 앤 드롭 배치** — 벤치↔선발 이동, 피치 위 자유 좌표 배치, 기본 위치 되돌리기.
- **11가지 포메이션** — 포메이션을 바꿔도 선수는 유지되고, 선수를 직접 드래그하면 형태를 자동 인식합니다(4-3-3 → 4-2-4).
- **역할 기반 자동 배치** — 득점·신장·caps·능력치에서 ST/윙/DM/CB 등 세부 역할을 추정해 최적 선발을 구성하고, 동률은 당일 컨디션으로 가릅니다.
- **선수 능력치 화면** — FC26 기준 35개 항목(6대 스탯 + 세부 능력치, GK 전용 5종), 주발·약발, 현재 컨디션, 사진과 출처를 함께 보여줍니다.
- **이름 표기 정규화** — 데이터셋의 법적 성명(중복 토큰·어색한 표기)을 대표팀 로스터 표기로 변환합니다(한국은 `Son Heung-min` 형식).
- **세트피스 지정** — 페널티킥·코너킥·프리킥 키커와 박스 침투 인원을 직접 정할 수 있습니다.
각 포메이션의 장단점은 문구를 적어둔 게 아니라 **시뮬레이션이 실제로 읽는 슬롯 좌표**에서 계산합니다. 설명과 경기 결과가 어긋날 수 없습니다.
 
| 포메이션 | 공격 성향 | 지역별 인원 | 좌우 폭 | 성격 |
|---|---:|:---:|---:|---|
| `5-4-1` | −0.90 | 5–4–1 | 21.0 | 실점 억제, 최전방 고립 |
| `5-3-2` | −0.60 | 5–3–2 | 18.0 | 수비 안정, 중원 열세 |
| `4-5-1` | −0.40 | 4–5–1 | 20.6 | 중원 우위, 마무리 인원 부족 |
| `5-2-3` | −0.10 | 5–2–3 | 20.8 | 두꺼운 수비 + 전방 3명, 중원 공백 |
| `4-4-2` | 0.00 | 4–4–2 | 21.6 | 균형 배치, 수적 우위 없음 |
| `4-2-3-1` | +0.10 | 4–5–1 | 18.6 | 더블 볼란치 기반 중원 장악 |
| `3-5-2` | +0.20 | 3–5–2 | 16.8 | 중원 과부하, 폭이 좁음 |
| `3-4-1-2` | +0.30 | 3–5–2 | 16.2 | 중앙 밀집, 측면 취약 |
| `4-1-2-3` | +0.45 | 4–3–3 | 19.2 | 앵커맨 기반 공격 전개 |
| `4-3-3` | +0.50 | 4–3–3 | 21.0 | 넓은 폭 + 전방 3명 |
| `3-4-3` | +0.90 | 3–4–3 | 19.6 | 총력전, 뒷공간 노출 |
 
### 컨디션 지수
 
선수별 컨디션(0~100)을 여섯 요인으로 계산해 게이지 색으로 보여줍니다. 같은 지표가 내 경기뿐 아니라 백그라운드로 돌아가는 다른 47개국 경기에도 적용됩니다.
 
| 요인 | 계산 | 효과 |
|---|---|---|
| 고도 | 1,000m부터 비선형 증가, 2,200m(아즈테카)에서 최대 | 감점 |
| 휴식일 | 직전 경기 이후 회복 일수 부족분 | 감점 |
| 최근 출전 시간 | 직전 경기 소화 분 (90분 = 최대) | 감점 |
| 이동 거리 | 직전 경기장에서의 비행 거리 (haversine) | 감점 |
| 시차 | 도시 간 UTC 오프셋 차이 | 감점 |
| 경험(caps) | A매치 출장이 많을수록 고도 페널티 상쇄 | 가점 |
 
### 전술
 
- **전술 스타일 6종** — 점유(패스) / 역습 / 측면(크로스) / 중앙 침투 / 롱볼 / 게겐프레싱. 각각 공격 전개·측면 오버래핑·직선성·전방 압박·역습 전환을 막대로 보여줍니다.
- **프리셋 4종** — 수비적(5-4-1) / 균형(4-2-3-1) / 공격적(4-3-3) / 초공격(3-4-3), 포메이션별 추천 스타일 표시.
- **세부 지시 19종** — 아래 표. 경기 중 변경은 미리 계산된 결과를 덮어쓰는 게 아니라 **다음 플레이부터** 시뮬레이션에 반영됩니다.
- **빠른 지시** — 여러 설정을 한 번에 바꾸는 상황별 버튼(리드 지키기, 경기 지배, 강한 압박, 측면 과부하, 만회 총공세).
- **내 전술 저장** — 직접 맞춘 설정에 이름을 붙여 최대 6개까지 저장하고 다음 경기에서 불러옵니다.
| 분류 | 지시 |
|---|---|
| 수비 | 수비 스타일(5) · 수비 라인(3) · 압박 강도(3) · 압박 시작 위치(3) · 마킹 방식(2) · 태클(3) |
| 공격 | 기회 만들기(4) · 정신력(5) · 템포(3) · 패스 스타일(4) · 공격 방향(4) · 슈팅 지시(3) |
| 팀 | 팀 폭(3) · 유동성(3) · 활동량(3) · 창의성(3) |
| 역할 | 공격수(3) · 미드필더(3) · 풀백(3) |
 
**선수 세부 역할 24종** — 표시용 라벨이 아니라 전진 정도·좌우 폭·슈팅 성향·압박 가담·패스 리스크·활동량을 실제로 바꾸며, 선택 시 장점과 위험을 함께 보여줍니다.
 
| 포지션 | 역할 |
|---|---|
| GK | 골라인 키퍼 · 스위퍼 키퍼 |
| CB | 스토퍼 · 커버 · 빌드업 센터백 |
| FB | 수비형 풀백 · 오버래핑 풀백 · 인버티드 풀백 |
| DM | 앵커맨 · 볼 위닝 미드필더 · 후방 플레이메이커 |
| CM | 박스 투 박스 · 중앙 지원 · 중앙 플레이메이커 |
| AM | 공격형 플레이메이커 · 쉐도우 스트라이커 · 프리롤 |
| W | 정통 윙어 · 인사이드 포워드 · 와이드 플레이메이커 |

### 라이브 경기
 
- **2D 애니메이션 진행** — 22명이 역할별로 다르게 움직이고, 득점 시 GOAL 연출 후 킥오프 대형으로 자동 복귀합니다.
- **19종 이벤트** — 패스 · 드리블 · 슈팅 · 골 · 실축 · 볼 회수 · 인터셉트 · 태클 · 블록 · 선방 · 파울 · 경고 · 퇴장 · 오프사이드 · 부상 · 코너킥 · 프리킥 · 스로인 · 페널티킥.
- **세트피스 대형** — 코너·프리킥·페널티에서 박스 인원, 수비벽, 키커 위치가 실제로 재배치됩니다.
- **재생 제어** — 배속 조절, 스페이스바 일시정지, 결과로 건너뛰기, 다시보기.
- **실시간 지표** — 점유율, 슈팅·유효슈팅, 패스 성공, 볼 회수, 파울·카드, 코너킥, 오프사이드, 기대 득점(xG).
- **선수 평점** — 양 팀 전 선수의 실시간 평점(터치·패스·드리블·태클·키패스·결정적 기회 실패·활동 거리 등 25개 이상 지표).
- **경기 중 스쿼드 조작** — 포메이션 변경, 역할 재지정, 교체를 경기 화면에서 바로 실행합니다.
### 경기 분석
 
- **히트맵** — 실제 위치 기록 기반의 볼 히트맵과 선수 포지셔닝 히트맵. 샘플 개수가 아니라 각 샘플이 대표하는 **시간**으로 가중하고 중앙값~97퍼센타일로 정규화해, 어디에 실제로 시간을 썼는지가 드러나게 했습니다.
- **패스·슈팅·탈취 지도** — 크로스 / 짧은 패스 / 스루패스 / 롱볼 / 일반 패스를 색으로 구분하고 유형별 필터링, 슈팅 위치와 방향, 공을 빼앗은 위치와 빼앗긴 위치를 각각 볼 수 있습니다.
- **필터** — 모든 뷰를 팀(우리/상대)·개별 선수·시간 구간(예: 전반 15~30분)으로 좁힐 수 있습니다.
- **상대 팀 분석** — 예상 선발, 실제 경기 데이터에서 관찰된 추정 포메이션, 예상 전술 성향(수비 라인·압박·템포·팀 폭), 강점·약점, 고지대 적응도, 상대 교체 명단.
- **상대 AI** — 상대도 스코어와 상황에 따라 전술을 바꾸고 고지대에서는 별도 적응 로직이 붙습니다. 바뀌면 알림으로 알려줍니다.
- **AI 전술 분석 · 실제 결과 비교** — 경기 후 실제 스탯을 근거로 전술 효과를 정리하고, 조별리그는 실제 2026 대회 결과와 스코어·전술을 비교합니다.
### 하프타임 · 교체 · 연장
 
- 전반 종료 후 스탯과 분석을 보고 포메이션·전술·선수 구성을 다시 짤 수 있습니다.
- 교체 카드 **5장**(연장 돌입 시 +1장). 인접 포지션으로만 교체 가능하고, 나간 선수는 재투입할 수 없습니다.
- 경고 누적·다이렉트 레드로 퇴장이 발생하며, 10명이 된 팀은 최전방 슬롯을 비우는 방식으로 대형이 실제로 축소됩니다(4-3-3 → 4-3-2).
- 토너먼트 동점 시 연장 30분, 이후에도 동점이면 승부차기를 킥 단위로 재생합니다. 키커는 직접 지정할 수 있습니다.

## 경기 엔진에 대해
 
승패를 확률로 굴리지 않고, **선수 22명의 위치를 시간 단위로 계산해 그 위에서 판정**합니다. 패스 성공률은 공을 가진 선수의 실제 여유 공간과 패스 경로의 수비수를 읽고, 슈팅은 자기 진영에 남은 수비 인원을 읽습니다. 그래서 포메이션과 선수 역할이 결과에 실제로 반영됩니다.
 
Elo는 개인 능력과 전술이 뒤집을 수 있는 범위로 제한된 팀 조직력 지표로만 작용하고, UI는 엔진 스냅샷을 그릴 뿐 패스·듀얼·슈팅 결과를 다시 계산하지 않습니다.
 
실축 통계 범위 안에 있는지 테스트로 고정해 두었습니다.
 
| 지표 | 시뮬레이션 | 실제 축구 |
|---|---|---|
| 합산 슈팅 | 24 | 24~26 |
| 합산 득점 | 2.5 | 2.6~2.8 |
| 코너킥 | 10.5 | 9~11 |
| 파울 | 18 | 20~22 |
| 인터셉트 | 45 | 40~50 |
| 퇴장 | 0.09 (11경기당 1회) | 약 0.1 |
 
`src/data/match/matchEngine.test.ts`, `scoreDistribution.test.ts`, `possessionAndRoles.test.ts`에서 검증합니다.
 
> 참고: `scoreDistribution.test.ts`의 극단 전술 시나리오 2건이 현재 실패 상태입니다(엔진 보정 진행 중).
