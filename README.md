# MatchplanXI

**선발 구성부터 경기 중 대응까지, 2026 월드컵을 직접 지휘하는 축구 감독 시뮬레이터**

**Live: https://matchplanxi.vercel.app/**

48개국 중 한 팀을 선택해 선발 명단과 포메이션을 구성하고, 선수별 역할과 팀 전술을 설계한 뒤 실시간 2D 경기에서 직접 대응하는 웹 기반 감독 시뮬레이터입니다. 조별리그 순위 경쟁부터 토너먼트, 연장전과 승부차기까지 하나의 대회 흐름으로 이어지며 경기 전 선택과 경기 중 지시가 이후 플레이와 결과에 반영됩니다.

---

## 실행 방법

**요구 사항**: Node.js 20 이상 (개발 환경 v24.18.0), npm

```bash
git clone https://github.com/jhwn223/MatchplanXI.git
cd MatchplanXI
npm install
npm run dev            # 개발 서버 (http://localhost:5173)
```

| 명령 | 설명 |
|---|---|
| `npm run dev` | 개발 서버 실행 |
| `npm run build` | 타입 검사 후 프로덕션 빌드 (`tsc -b && vite build`) |
| `npm run preview` | 빌드 결과 로컬 확인 |
| `npm run lint` | oxlint 정적 분석 |
| `npm test` | 전체 테스트 (vitest, 23개 파일 / 122개 케이스) |
| `npm run test:match` | 경기 엔진 보정 테스트만 실행 |
| `npm run sync:player-photos` | Wikimedia Commons에서 선수 사진·출처 갱신 |
| `npm run sync:player-photos -- --team=KOR` | 특정 대표팀만 갱신 |

`main` 브랜치가 갱신되면 Vercel에서 프로덕션 빌드를 배포합니다.

│  ├─ conditionEngine.ts       고도·이동·휴식 기반 컨디션 지수
│  ├─ formation.ts             포메이션 정의 및 드래그 형태 자동 감지

## 핵심 기능

- **월드컵 전체 대회 진행**: 48개 대표팀 중 한 팀을 선택하면 2026 월드컵 일정에 맞춰 조별리그를 시작합니다. 사용자의 경기 결과와 다른 조의 시뮬레이션 결과가 순위표에 누적되고, 조별리그 종료 후 32강부터 결승까지 대진표가 이어집니다.
- **선발 명단과 자유로운 포메이션 구성**: 11가지 기본 포메이션을 선택하거나 11인 자동 배치로 선발을 빠르게 구성할 수 있습니다. 피치와 벤치 사이에서 선수를 드래그하고 피치 위 위치를 자유롭게 조정하면 새로운 형태를 자동으로 감지하며, 포메이션을 변경해도 배치된 선수는 유지됩니다.
- **포지션별 역할 지정**: 역할은 선수 개인이 아니라 포메이션 슬롯에 지정됩니다. 골키퍼, 센터백, 풀백, 미드필더, 윙어, 공격수마다 서로 다른 역할을 선택할 수 있고 선수를 교체해도 해당 위치의 역할과 전술적 임무는 그대로 이어집니다.
- **경기 전 팀 전술 설계와 저장**: 공격 성향, 템포, 패스 방식, 공격 폭, 압박, 수비 라인과 같은 세부 지시를 조합할 수 있습니다. 완성한 전술은 이름을 붙여 저장하고 이후 경기나 경기 중 빠른 지시에서 다시 불러올 수 있습니다.
- **상대 분석을 활용한 경기 준비**: 상대의 예상 포메이션, 선발 평균 컨디션, 전술 성향, 강점과 약점, 교체 명단을 경기 전에 확인할 수 있습니다. 상대가 어떤 공간을 활용하고 어떤 위험을 노출하는지 살펴본 뒤 선발과 전술을 조정할 수 있습니다.
- **선수 능력치와 컨디션 기반 선택**: 선수 카드를 누르면 종합 능력치와 세부 스탯을 확인할 수 있습니다. 체력과 컨디션은 출전 시간, 휴식, 이동 거리, 시차, 경기장 환경 등의 영향을 받아 누적되므로 매 경기 같은 선발만 반복하기보다 선수단 전체를 운영해야 합니다.
- **실시간 2D 경기와 사건 누적**: 선수 22명과 공이 포메이션, 역할, 능력치와 현재 전술에 따라 움직이며 패스, 드리블, 태클, 슈팅, 선방, 파울과 득점 사건이 시간 순서대로 발생합니다. 킥오프 전에 결과를 정하지 않고 경기 흐름이 쌓이면서 최종 스코어와 선수 평점이 만들어집니다.
- **경기 중 전술 대응**: 경기 분석, 전술, 스쿼드·교체, 상대 분석 탭을 오가며 현재 상황을 확인할 수 있습니다. 빠른 지시로 경기 운영 방향을 즉시 바꾸거나 팀 전술과 포메이션을 다시 조정할 수 있으며 변경 내용은 이후 플레이부터 반영됩니다.
- **하프타임, 교체, 연장전과 승부차기**: 하프타임에는 전반 통계와 선수 상태를 확인한 뒤 포메이션과 전술을 정비할 수 있습니다. 기본 5장의 교체 카드를 적용하고 연장전에서는 추가 교체와 승부차기 키커 순서 지정까지 지원합니다.
- **경기 통계와 전술 분석**: 점유율, 슈팅과 유효 슈팅, 기대 득점, 패스 성공률, 활동량과 선수 평점을 실시간으로 확인할 수 있습니다. 선수 포지셔닝·볼 체류 히트맵, 패스·슈팅·탈취·소유권 상실 지도를 통해 전술 변경 전후의 경기 흐름을 비교할 수 있습니다.
